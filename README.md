# VK AI Bot

AI-бот для сообщества ВКонтакте. Отвечает на личные сообщения с помощью OpenAI,
помнит контекст диалога с каждым пользователем и умеет общаться в трёх режимах.

- Получает сообщения через **Bots Long Poll API** (библиотека [VKBottle](https://github.com/vkbottle/vkbottle)), публичный сервер не нужен.
- Отвечает через **OpenAI Chat Completions API**.
- Хранит последние 20 сообщений диалога в `users/{user_id}.json`.

## Установка

Нужен Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate   # Windows PowerShell
pip install -r requirements.txt
cp .env.example .env
python main.py
```

## Настройка `.env`

| Переменная | Обязательна | Что это |
|---|---|---|
| `VK_TOKEN` | да | Ключ доступа сообщества |
| `VK_GROUP_ID` | да | Числовой ID сообщества |
| `OPENAI_API_KEY` | да | Ключ OpenAI API (`sk-...`) |
| `OPENAI_MODEL` | нет | Модель OpenAI, по умолчанию `gpt-5.4-mini` |

Если обязательной переменной нет, бот не стартует и пишет, какой именно.

### Как получить ключи ВКонтакте

1. **Ключ сообщества:** Управление сообществом → Дополнительно → Работа с API → Ключи доступа →
   **Создать ключ**. Отметьте права **«Сообщения сообщества»** и **«Управление сообществом»**.
2. **Long Poll:** там же, вкладка **Long Poll API** → включить, версия API — последняя.
   На вкладке **Типы событий** включите **«Входящее сообщение»** (`message_new`).
3. **Сообщения:** Управление → Сообщения → включить **«Сообщения сообщества»**;
   там же в **Настройках для бота** включите **«Возможности ботов»**.
4. **ID сообщества:** число из адреса `vk.ru/club123456789` или в разделе «Работа с API».

### Ключ OpenAI

[platform.openai.com/api-keys](https://platform.openai.com/api-keys) → **Create new secret key**.
На аккаунте должен быть положительный баланс.

### Антивирус и ошибка `CERTIFICATE_VERIFY_FAILED`

Некоторые антивирусы (например, Касперский) проверяют HTTPS и подменяют сертификат сайта своим.
Python по умолчанию доверяет только своему встроенному списку сертификатов и такое соединение
отвергает. Поэтому бот при старте подключает [truststore](https://github.com/sethmlarson/truststore)
и проверяет сертификаты по системному хранилищу ОС — так же, как браузер. Проверка сертификатов
при этом не отключается.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и список режимов |
| `/mode` | Показать текущий режим |
| `/mode assistant` | Полезный ассистент: понятно и по делу |
| `/mode friend` | Дружелюбный собеседник: неформально, коротко, с эмодзи |
| `/mode expert` | Эксперт-консультант: структурированно, со списками и уточнениями |
| `/reset` | Очистить историю диалога (режим сохраняется) |

Команды обрабатываются локально и не отправляются в LLM. Любой другой текст уходит в модель
вместе с историей диалога.

## Структура

```
main.py              — точка входа: логирование, конфиг, запуск бота
bot/config.py        — чтение и проверка .env
bot/vk_client.py     — VKBottle, Long Poll, обработка команд и сообщений
bot/llm_client.py    — запросы к OpenAI Chat Completions
bot/memory.py        — история диалогов в users/{user_id}.json
bot/modes.py         — режимы общения и system-промпты
users/               — истории диалогов (в git не попадают)
```

## Как это работает

1. Пользователь пишет сообществу в личные сообщения (сообщения из бесед бот игнорирует).
2. Если это команда — бот отвечает сам, без LLM.
3. Иначе бот загружает историю пользователя, отправляет в OpenAI system-промпт режима,
   историю и новое сообщение, сохраняет пару «вопрос — ответ» и отвечает.
4. Если OpenAI недоступен, пользователь получает вежливое сообщение о временной проблеме,
   ошибка пишется в лог, а история не меняется.

Формат `users/{user_id}.json`:

```json
{
  "mode": "assistant",
  "history": [
    {"role": "user", "content": "Меня зовут Vik"},
    {"role": "assistant", "content": "Приятно познакомиться, Vik!"}
  ],
  "updated_at": "2026-10-15T18:00:00+00:00"
}
```
